# Physistrong

Self-hosted exercise and fitness tracker, built to expose training data the
way I actually want it. A Laravel API with a React single-page frontend,
designed to run entirely on a private LAN with no cloud dependencies.

## Stack

- **Backend:** Laravel 13 (PHP), MySQL
- **Frontend:** React + Vite (TypeScript)
- **Hosting:** Self-hosted LEMP, Docker

## Status

Early. The project is in spec review and planning: requirements are being
reconstructed before the application is rebuilt on the current stack. Setup
and development instructions will land here once the application is
scaffolded.
